# Krish Nigam — Portfolio Website

Personal portfolio of **Krish Nigam**, B.Tech Computer Science Engineering student based in Bhopal, India.

## Features
- **Modern Responsive Design**: Built with semantic HTML5, modern Tailwind CSS, and Alpine.js.
- **Dark / Light Theme Toggle**: Persistent user theme preference stored via `localStorage`.
- **Selected Projects**:
  - *Campus Market*: College peer-to-peer student marketplace built with PHP, MySQL, and XAMPP.
  - *ApexPlanet Web Portal & Health Tools*: Web development internship projects including user accounts and interactive BMI Calculator.
  - *CodeAlpha Python & Algorithm Suite*: Algorithmic solutions, tuple processing, and practical utilities.
  - *Hackathon Technical Prototype*: System architecture, presentation, and evaluation model.
- **Practical Experience & Leadership**: ApexPlanet internship, CodeAlpha certified internship, and Class Representative (CR) / Coordinator role.
- **Case Study**: Full technical write-up for Campus Market ([case-study.html](case-study.html)).

## Structure
- `index.html`: Main portfolio landing page with Hero, Focus Areas, Projects, Experience, About, and Contact form.
- `projects.html`: Filterable directory of all projects (Web Dev, Python & DSA, Internships, Systems & Academic).
- `case-study.html`: In-depth project case study for *Campus Market*.
- `krish_avatar_clean.png`: High-resolution circular profile avatar.
- `campus_market.jpg`: Project preview mockup for Campus Market.
